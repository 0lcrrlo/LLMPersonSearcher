여태까지 구현한 파이프라인(자연어 파싱, Pydantic 스키마 검증, Ollama 연동, DB Few-Shot 관리 등)을 실행하기 위해 필요한 다운로드 항목과 설치 명령어 정리입니다.

---

### 1. 필수 시스템 프로그램 (System Software)

| 프로그램 | 설명 | 설치 방법 |
| --- | --- | --- |
| **Python 3.10+** | 코드 실행 환경 | [python.org](https://www.python.org/)에서 다운로드 및 설치 |
| **Ollama** | 로컬 LLM 구동 엔진 | [ollama.com](https://ollama.com/)에서 다운로드 및 설치 |

---

### 2. Ollama 로컬 LLM 모델 다운로드

Ollama 설치 완료 후, 터미널(CMD 또는 PowerShell)에서 아래 명령어를 실행하여 파싱 모델을 다운로드합니다.

```bash
ollama pull qwen2.5:7b

```

---

### 3. 필수 파이썬 라이브러리 (Python Packages)

| 패키지명 | 용도 |
| --- | --- |
| **`ollama`** | 파이썬 코드에서 로컬 Ollama 모델 호출 및 통신 |
| **`pydantic`** | LLM 출력 결과 데이터 구조화 및 타입 검증 |
| **`google-genai`** *(선택)* | Gemini API 연동 코드를 사용할 경우만 필요 |

> **참고**: `sqlite3` 및 `json`, `random`, `time` 모듈은 파이썬 기본 표준 라이브러리에 포함되어 있어 별도로 설치할 필요가 없습니다.

---

### 4. 한 번에 설치하는 터미널 명령어

터미널(CMD / PowerShell / VS Code Terminal)을 열고 아래 명령어를 순서대로 실행하세요.

```bash
# 1. 파이썬 라이브러리 일괄 설치
pip install ollama pydantic

# 2. 파싱용 LLM 모델 다운로드
ollama pull qwen2.5:7b

```
